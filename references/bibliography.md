# References

Full-text PDFs of the sources below are **not** committed to this repository — several are copyrighted journal articles, a thesis, and a commercial textbook. They're kept locally on the project owner's machine for personal reference. This file exists so the repo still documents what informed the design without redistributing anyone else's copyrighted work.
